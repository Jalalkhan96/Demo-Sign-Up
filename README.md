# Demo Sign Up

A small sign-up card demo — a centred form on a blue gradient page with decorative circles.

## What it is

A single-page sign-up form example (the header itself says "It Is Just Example"). A 400px card (`.inner-box`) sits in the middle of a full-screen gradient (`.outer-box`) and holds three required fields — Full Name, Your Email Here, Your Password — plus a "Create Account" submit button and an "Already Have Account? Login" footer line. Two translucent gradient circles (`.circle.c1` and `.ccircle.cc1`) are positioned in opposite corners as decoration. The form's action is `#`, so it is a visual demo only and creates no account.

## Files

- `index.html` — the sign-up card markup: header, the three-field form, footer, and the two decorative circles.
- `style.css` — Segoe UI type, the `#3ed8ff` → `#a8f5ff` gradient background, card shadow/positioning, input and button styling with hover states.
- `Deployment` — text file recording the GitHub Pages URL this page was deployed to.
- `README.md` — this file.

## Run it

Open `index.html` in a browser.
